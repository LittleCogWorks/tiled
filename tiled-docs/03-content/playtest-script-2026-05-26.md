# Tiled v1 Playtest Script (One Page)

Date: 2026-05-26  
Purpose: validate disconnect clarity, early-guess incentives, and LPS fairness before any gameplay code changes.

## Session Setup (3 minutes)

1. Players: 2-4
2. Target score: 200
3. Build note to tell players:
   - Wrong guesses are expected during testing.
   - You are testing fairness and clarity, not just winning.
4. Capture template:
   - Start time
   - End time
   - Questions played
   - Winner score
   - Any confusion moments (short notes)

## Rule Brief To Read Aloud (30-45 seconds)

1. Guessing risk is freeze/turn loss only; no point deduction.
2. Early guesses should feel rewarded.
3. If only one guesser remains (LPS), all tiles show and they get one free final guess.
4. Network disconnects should be visible and understandable to all players.

## Test Variants (run 2-3 mini matches)

Use one variant per mini match:

1. Variant A: Early +10, Mid +5, LPS 60%
2. Variant B: Early +12, Mid +6, LPS 60%
3. Variant C: Early +10, Mid +5, LPS 65%

## During Match - Moderator Checklist

1. Watch for hesitation to guess early.
2. Watch reactions when someone guesses wrong.
3. Trigger one controlled phone lock/sleep disconnect if possible.
4. Record whether players notice disconnect state without explanation.
5. Record if LPS feels exciting or too swingy.

## Post-Match Questions (ask every player)

1. Did you understand what happens after a wrong guess?
2. Did guessing early feel worth it?
3. Did LPS feel fair?
4. Was game length right for a quick replayable session?
5. Were disconnect/reconnect messages clear enough?
6. Did any scoring moment feel cheap or confusing?
7. Would you play again immediately?

## Pass/Fail Gates

Pass this tuning set if all are true:

1. At least one voluntary early guess happened in most rounds.
2. No player reports "double punishment" feeling.
3. Disconnect behavior is understood within 3 seconds by observers.
4. LPS is rated fair by most players.
5. Game still feels quick (target band remains near current pace).
